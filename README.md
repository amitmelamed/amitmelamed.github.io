# Amit Melamed — interactive CV

Game & Algorithm Developer (Unreal C++, destruction, AI, multiplayer).

A single-page CV over a procedural low-poly island that is generated and destroyed live in the browser
(Three.js + Rapier physics). Open `index.html` through any static host; no build step.

- Procedural island, town, trees and eroded terrain, generated per seed (`#s<number>` in the URL)
- Voronoi-fracture destruction with rigid-body physics
- Phone-friendly CV sheet, cinematic showreel
